Este proyecto es una landing page de una empresa en el giro de la tecnologia, las secciones se divide en:
- Optimización Comercial y Analítica
- Arquitectura e Infraestructura Cloud
- Ciberseguridad Avanzada y Cumplimiento
- Soporte de Cómputo e Infraestructura Física
- Tonal-Tech Labs
- Academy

Se busca que sea la entrada principal de los usuarios generales, tanto para cotizar como para acceder a recursos especificos como lo es Labs y Academy.

-- para entender un poco mejor el funcionamiento, las primeras 4 secciones son cotizables y se busca que tenga integración de IA que pregunte lo necesario (relacionado a la seccion) y que esta genere la cotización basado en lo recolectado y parametros asignados en la base de datos, y si se requiere, mandar a consulta con un agente (humano).
Actualmente, no se tiene la infraestructura para estaintregracion y se busca que primero sea manual y poco a poco migrar a la cotizacion automatizada por IA.

-- Labs es la sección donde estaran listados todos lo desarrollos mobiles generados por la empresa que posiblemente tengan precio o no, al seleccionar una te abre toda la info de la app, el link para descargar y un trailer desde youtube.

-- Academy es la sección para mostrar los cursos que ofrece la empresa, esta sección si necesita un login para acceder.
los cursos deben funcionar similar a udemy, que se tienen gratuitos, o de pago, usando stripe.

y como extras, se deberia tener un dashboard oculto para administradores, este dashboard o panel, servira para agregar cursos, gestionar tipo pago o gratuito, metricas de acceso y saber a que seccion entran mas los usuarios.


############################################
El desarrollo sigue un ciclo iterativo compuesto por las siguientes fases, que se repiten en cada iteración:

1. **Planificación**
2. **Requerimientos**
3. **Diseño**
4. **Codificación**
5. **Pruebas / Test**
6. **Deploy**
7. **Mantenimiento**
8. Se reinicia el ciclo desde **Planificación**.
